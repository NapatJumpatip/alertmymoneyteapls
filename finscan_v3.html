🌲 Isolation Forest Pipeline

1
Feature Engineering — สร้าง features จาก amount, rolling stats, วัน/เดือน และ TF-IDF text
2
Normalise — Min-Max scaling ทุก feature ก่อนส่งเข้า model
3
Isolation Forest — 100 trees สร้าง random partitions, transaction ที่ isolate ได้เร็ว = anomaly
4
IQR Filter — Q3 + 2.5×IQR กรอง false positive เพิ่มเติม
5
Whitelist — ข้าม transaction ครอบครัว Jumpatip โดยอัตโนมัติ
